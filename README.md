# Journal Hub

A single-page static website for a research academy or journal repository. No build step, no dependencies.

## Edit
- Journals: the `journals` array near the bottom of `index.html`
- Name, address, phone, email: search for `Your Research Academy` and `example.org`
- Colors: the `:root` variables at the top of the `<style>` block

## Publish on GitHub Pages
1. Push `index.html` and this README to a new repository.
2. Go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Your site appears at `https://<username>.github.io/<repo>/` after a minute or two.
